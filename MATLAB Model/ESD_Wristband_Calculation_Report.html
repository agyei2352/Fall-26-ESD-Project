Smart ESD Wristband: Electrical and Waveform Calculations

MATLAB Model | Calculation reference | 9 November 2026

Model scope. This report documents the bare nRF52840 plus CR2032 design target and the bench-equivalent signal calculations. The source is set to the CR2032's nominal 3.0 V; real cell voltage and current capability vary with age, temperature, and load and are not simulated here. R/C values are illustrative, not calibrated human-skin, fit, or moisture properties. A CR2032 is primary and must never be charged.

1. Circuit model

The pulse travels through a 1 MOhm limit resistor, Nylon A, the modeled skin/contact impedance, and Nylon B. The ADC senses Nylon B relative to MCU ground. A 1 MOhm return resistor connects Nylon B to MCU ground.

2. Settled amplitude and resistance

At the settled pulse plateau, the capacitor is an open circuit. Rlimit, Rskin, and Rground form a series path, so the current and ADC voltage are:

Iplateau = Vdrive / (Rlimit + Rskin + Rground) Vplateau = Iplateau * Rground = Vdrive * Rground / (Rlimit + Rskin + Rground) Rskin = (Vdrive * Rground / Vplateau) - Rlimit - Rground

For an open resistive path, Vplateau approaches 0 V through Rground. In firmware, a sense value at or below 0.02 V is treated as an invalid/open path.

3. RC edge and settling calculations

For the capacitor in parallel with Rskin, the initial rising-edge voltage is calculated with Cskin acting as a short at t = 0+:

Vinitial = Vdrive * Rground / (Rlimit + Rground) = 3.0 * 1M / (1M + 1M) = 1.500 V Rth = Rskin || (Rlimit + Rground) = Rskin * (Rlimit + Rground) / (Rskin + Rlimit + Rground) tau = Rth * Cskin Vadc(t) = Vplateau + (Vinitial - Vplateau) * exp(-t / tau) EdgeDrop(t) = Vadc(t) - Vplateau Tsettle_5%_transient = -ln(0.05) * tau = 2.9957 * tau Tsettle_5%_final = -tau * ln(0.05 * Vplateau / abs(Vinitial - Vplateau))

These are different criteria. For 40 MOhm / 10 nF, 57.06 ms reduces the transient to 5% of its initial amplitude, but the sense voltage is not within 5% of the much smaller final plateau until about 114.12 ms.

Increasing Rskin lowers the settled amplitude and also changes tau. Increasing Cskin at fixed Rskin leaves the DC plateau unchanged but increases the settling time. This model therefore separates amplitude and transient features for analysis; it does not prove which real-world condition caused a change.

4. Status and waveform interpretation

  • Green / Good: connected-path resistance below 5 MOhm.
  • Yellow / Warning: 5 MOhm through 35 MOhm, inclusive.
  • Red / Fail: resistance above 35 MOhm or an open/invalid path.
  • Early voltage, edge drop, and settling time are logged for analysis, but are not currently used to label fit or moisture.
Interpretation limit. Fit, sweat/moisture, contact area, pressure, movement, and wiring parasitics may all affect measured impedance or waveform features. Separate fit/moisture classification requires controlled experiments, independent labels, repeatability analysis, and calibration. The illustrative capacitor values must not be presented as measured skin properties.

5. MATLAB integration

The script esd_wristband_status_model.m calculates the settled threshold table and the RC waveform feature table. On each run it exports:

  • ESD_Wristband_Status_Calculations.csv
  • ESD_Wristband_Waveform_Calculations.csv

These output tables are written beside the MATLAB script and can be used to compare future measurements. Change one model parameter at a time when investigating sensitivity.
